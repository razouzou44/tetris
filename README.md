# ☄️ Tetris Cruel

> *"Good luck. You'll need it."*

A Tetris that doesn't want you to win. Terrible pieces guaranteed, brutal speed, sarcastic taunts... and meteorites crashing down every 5 seconds.

🔗 **Play now:** [razouzou44.github.io/tetris](https://razouzou44.github.io/tetris/)

---

## 🎮 Controls

| Key | Action |
|---|---|
| ← → | Move piece |
| ↑ | Rotate |
| ↓ | Soft drop |
| **Space** | Hard drop |
| **P** | Pause |

Mobile: on-screen touch buttons included.

---

## ☄️ The Meteorite

Every **5 seconds**, a meteorite strikes the board:

1. **Warning** — target column flashes orange, big alert on screen
2. **Fall** — glowing fireball with trail and sparks
3. **Impact** — explosion, screen shake, crater blasted into the bricks
4. **Bonus** — +50 pts per brick destroyed

The column is **random**. It can save you or destroy your best setup. Pure chaos.

---

## 😈 Cruel Features

- **Evil piece randomizer** — more S and Z pieces when the stack is high, I-piece is rare
- **Speed escalates** every 5 lines cleared
- **Sarcastic taunts** in real time:
  - *"Pathetic."*
  - *"My grandmother plays better."*
  - *"Statistically, you won't improve."*
  - *"Wow. Just... wow."*
- **Rage bar** that fills up as the stack grows
- **Death counter** — for the brave (or the masochistic)
